# 📜 Changelog: Rekapan Mitra (aplikasi mobile)

Perubahan aplikasi iOS dan Android. Versi web punya changelog sendiri di `CHANGELOG.md` (root).
Aturan versi ada di `docs/VERSIONING.md`.

---

## [1.0.0] - Rilis pertama
### ✨ Added
- Catat order dengan harga otomatis menyesuaikan jumlah, jenjang pelanggan, dan level mitra (termasuk level kustom).
- Beranda: omset, untung, order yang perlu dikerjakan, dan target bulanan dalam rupiah dan botol.
- Riwayat order dengan pencarian, filter status, serta pemilih bulan dan tahun.
- Stok dan catat restok, pelanggan, pengeluaran dan pemasukan, target bulanan, serta toko online.
- Isi order dari chat dengan AI.
- Onboarding: sambutan, daftar, verifikasi email, dan lengkapi profil tiga langkah.
- Hapus akun dari menu Akun.

### 📋 Release Type
- **Major**: rilis pertama ke App Store dan Play Store.
